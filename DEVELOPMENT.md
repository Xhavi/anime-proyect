# Nébula Anime — MVP

Primera versión de catálogo original, responsive, con series ficticias y espacios reservados para publicidad.

## Ejecutar localmente

Desde la carpeta del repositorio:

```bash
python -m http.server 8080
```

Abrir http://localhost:8080. También se puede abrir `index.html` directamente.

## Incluye
- Inicio destacado y tarjetas de series
- Catálogo con filtros y búsqueda
- Detalles y lista de episodios
- Pantalla de reproductor de demostración **sin transmisión**
- Calendario provisional
- Espacios publicitarios sin scripts externos
- Página preliminar de privacidad
